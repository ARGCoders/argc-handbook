# XP System

XP is how ARGC measures contribution. It is earned through evaluations completed, events organized, cross-node work, and verified community output — not through attendance or visibility. XP determines tier advancement, and regression is possible: the number reflects what you are doing now, not what you did six months ago.

## What XP Is

XP is a quantified record of contribution. It is not a score for effort, presence, or intention. It is a record of verified output.

The system exists because informal accountability stops working at scale. When the club was small, a Node Leader could track every member's contribution from memory. As ARGC grows, the platform carries that memory. XP is the language the platform uses.

## How You Earn XP

| Activity | XP Weight |
|----------|-----------|
| Peer evaluation completed (on schedule) | Standard |
| Peer evaluation completed (late, notified) | Reduced |
| Event organized or facilitated | Standard–High (based on scope) |
| Knowledge session delivered | Standard |
| Cross-node contribution (verified) | Standard |
| Hackathon participation with deliverable | High |
| External outreach with documented outcome | High |

XP weights are reviewed by Super Peers each cycle. Activities that become easy to game will have their weights adjusted.

## What XP Controls

- **Tier placement** — XP thresholds determine which tier a member sits in
- **Voting weight** — higher-tier members carry more weight in club votes
- **Leadership eligibility** — Node Leader and Super Peer roles require sustained XP above threshold

## What XP Does Not Do

XP does not make you a good engineer. It does not substitute for judgment. It does not override the humans reviewing the records behind the numbers.

A member with high XP who behaves in ways that damage the collective will be reviewed on those grounds, regardless of their XP total. The system is a signal, not a verdict.

## Decay and Regression

XP is not permanent. Inactive cycles result in decay — the rate depends on how long the inactivity continues.

This is intentional. ARGC does not carry inactive members in good standing. If you are not contributing, your tier should reflect that.
