# The ARGC Handbook

**ARGC** (Alliance of Resilient Giveback Coders) is a production-oriented engineering collective at 42 Amman.

This handbook documents how we operate, what we stand for, and what we expect from every member. It is public by design — the standard we hold ourselves to should be visible to anyone who wants to evaluate us.
